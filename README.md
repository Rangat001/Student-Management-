# Student Management System

A simple **Student Management** application built entirely in Java. This project is designed to help manage student records efficiently, making it suitable for small institutions or as a learning project for understanding Java concepts.

## 📌 Overview

The Student Management System is a mini project that provides functionalities to:
- Add, update, and delete student records
- View a list of all students
- Search for students by their ID or name
- Maintain a structured and organized database using Java

This project is ideal for beginners looking to explore object-oriented programming concepts and file handling in Java.

## 🚀 Features

- **Add Students**: Easily add new student records.
- **Update Student Details**: Modify existing student information.
- **Delete Records**: Remove outdated or incorrect entries.
- **Search Students**: Quickly find a student using their ID or name.
- **View All Records**: Display the full list of students in a structured format.

## 💻 Technology Stack

- **Programming Language**: Java (100%)
- **Database**: MySQL
